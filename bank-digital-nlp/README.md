# 基于年报文本挖掘的商业银行数字化转型测度研究（预演毕业论文）

> 课程作业：金融文本挖掘与NLP测度构建 · 2023级金融1班 · 指导教师：王宇扬
>
> 在线项目主页：https://kuli663.github.io/bank-digital-nlp/

## 研究概览

- **选题**：运用NLP测度构建方法，基于上市商业银行年报文本，构建2015—2024年银行—年度层面的**数字化转型指数**，并完成完整的信度与效度检验。
- **样本**：12家上市银行 × 10年 = 120个银行—年度观测（预演阶段使用随机种子固定的**模拟语料**，真实值已知，便于验证方法有效性）。
- **核心结果**：
  - 指数十年单调上升（2015年2.75 → 2024年3.78），招行、平安、宁波银行居前；
  - 四维度得分 Cronbach's α = **0.681**（形成式指标，接近可接受门槛）；
  - 指数与ROA相关系数 **0.479**；OLS回归系数 **0.282**（t = 6.98，1%显著），R² = 0.425，效标效度良好。

## 五步流水线

| 步骤 | 内容 |
| --- | --- |
| Step 1 数据获取 | 构建银行—年度年报文本语料（模拟，SEED=20261010固定） |
| Step 2 文本预处理 | 正则清洗标点/空白/数字/字母，保留纯汉字序列 |
| Step 3 词典构建 | 加载四维27词词典（数字技术/渠道/产品与服务/战略与组织） |
| Step 4 测度计算 | 关键词词频法：DigitalIndex = ln(1+总词频)，另输出四维得分 |
| Step 5 信效度检验 | 描述统计 → Cronbach's α → 相关分析 → OLS回归 |
