# 数据来源说明

本文件用一句话说明仓库中每个文件的来源与处理步骤。

| 文件 | 来源与处理步骤（一句话） |
| --- | --- |
| `code/pipeline.py` | 作者编写的五步流水线脚本（语料构建→预处理→词典加载→指数计算→信效度检验与回归），纯Python标准库，固定随机种子SEED=20261010保证完全可复现。 |
| `data/digital_dictionary.txt` | 作者参照吴非等(2021)五维框架与银保监会《关于银行业保险业数字化转型的指导意见》政策话语，结合上市银行年报MD&A高频表述整理的四维27词数字化转型词典。 |
| `data/bank_digital_index_panel.csv` | 由`pipeline.py`自动生成的12家银行×2015-2024年面板（120行），包含文本长度、关键词词频、数字化转型指数、四维得分及模拟财务变量（ROA、lnAssets），UTF-8-BOM编码可直接用Excel打开。 |
| `results/analysis_results.json` | 由`pipeline.py`自动输出的检验结果，含描述性统计、Cronbach's α=0.681、指数与ROA相关系数0.479、年度均值序列与OLS回归系数（β=0.282, t=6.98, R²=0.425）。 |
| `thesis/预演毕业论文.md` / `.docx` | 作者撰写的预演毕业论文全文（约6900字），Markdown为源文件，Word版由`code/md_to_docx.py`自动转换生成。 |

**重要说明**：本研究为预演毕业论文，年报文本语料与财务变量均为**模拟数据**（生成机制见论文"研究设计"部分及代码注释），目的是在真实值已知的条件下验证测度方法的有效性；正式论文阶段将从巨潮资讯网下载真实年报PDF替换语料。
